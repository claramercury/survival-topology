## 2024-05-18 - [Missing Responsible Disclosure Policy]
**Vulnerability:** The project lacked a defined private vulnerability reporting mechanism. This could lead to security issues being disclosed publicly, creating a window of exploitation before a fix is available.
**Learning:** Implementing a clear SECURITY.md that mandates private disclosure (e.g., via email) reduces the risk of zero-day exploits and ensures responsible handling of vulnerabilities.
**Prevention:** Always include a SECURITY.md file in projects, directing security reports to a private channel rather than public issue trackers.
