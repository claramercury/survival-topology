# Security Policy

## Supported Versions

The "Survival Topology" project is an evolving conceptual framework. We currently support the latest draft of the documentation and associated concept implementations.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We prioritize the security of the concepts and reference implementations described in the "Survival Topology" framework.

If you discover a vulnerability or security issue, please practice **private responsible disclosure**. Do not open a public issue or expose vulnerability details in a public pull request.

Please report any security concerns directly to the project author:
**Eric Lin**: [eric26752196@gmail.com](mailto:eric26752196@gmail.com)

When reporting a vulnerability, please include:

* A clear description of the vulnerability.
* Steps to reproduce the issue.
* Potential impact.
* (Optional) Suggestions for a fix.

We will endeavor to respond to your report promptly.

## Security Updates

Security updates will be addressed through private channels before being merged into the main repository. Public announcements regarding security fixes will avoid exposing exploitable details.
