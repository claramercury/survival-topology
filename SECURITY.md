# Security Policy

## Supported Versions

Since this project primarily consists of the theoretical "Survival Topology" documentation, all security reports should target the current `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project and its concepts seriously.

If you discover a critical security vulnerability or an architectural flaw within the project, please practice private responsible disclosure.

Do not open a public issue. Instead, please report it privately by sending an email directly to the author, Eric Lin, at:

**eric26752196@gmail.com**

Please include the following details in your report:

- A description of the vulnerability or security flaw.
- Instructions on how to reproduce or verify it.
- The potential impact.

We will endeavor to respond to your report promptly. Thank you for helping to improve the security of the Survival Topology project!
