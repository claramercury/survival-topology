# Security Policy for Survival Topology

## Supported Versions

Currently, the master version of the "Survival Topology" documentation framework is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

As the Sentinel of this project, ensuring the conceptual and structural integrity of the Wh- Protocol is paramount. We take all security vulnerabilities seriously.

**Private Responsible Disclosure:**
If you discover a security vulnerability, we strongly mandate that you practice private responsible disclosure. **Do not open public issues or pull requests for security vulnerabilities**, as this could expose the framework to premature conceptual exploitation.

Please report all security vulnerabilities privately to the author:
**Eric Lin** - [eric26752196@gmail.com](mailto:eric26752196@gmail.com)

We will respond to your report as quickly as possible. When reporting a vulnerability, please include:

- A detailed description of the vulnerability.
- Any relevant context or steps to reproduce the issue.
- Potential impact on the Survival Topology framework.

Thank you for helping to protect the integrity of the system.
