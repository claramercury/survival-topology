# Security Policy

## Supported Versions

Currently, as this is a theoretical documentation and framework repository for the Survival Topology, there are no software versions to maintain.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or propose a significant security enhancement for the framework's theory, please report it.

Please do not open a public issue for critical vulnerabilities. Instead, send a direct report or use GitHub's private vulnerability reporting feature if enabled. We will aim to acknowledge the report within 48 hours.
