# Security Policy

## Supported Versions

The "Survival Topology" project is currently conceptual. Security patches or updates apply primarily to the integrity of the theoretical framework and documentation on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a critical component of any closed-loop control system. If you discover any potential vulnerabilities, design flaws, or logical exploits in the **"Wh- Protocol"** architecture or the documentation structure, please report them to us securely.

### **Private Disclosure**

We practice responsible private disclosure. **Do not open a public GitHub issue** to report potential security vulnerabilities. Instead, please report vulnerabilities directly to the author:

**Email:** [eric26752196@gmail.com](mailto:eric26752196@gmail.com)

Please provide a detailed description of the potential vulnerability, including steps to reproduce or conceptualize the exploit.

We will review the issue and, if valid, implement a fix or clarification in the theoretical framework. We appreciate your efforts to secure the architecture!
