# Security Policy for Survival Topology

## Supported Versions

Since this project primarily hosts conceptual architectural documentation and theory (The "Wh- Protocol"), standard software versioning lifecycle does not directly apply.

Currently, all conceptual revisions and updates applied to the `main` branch are considered the active version.

## Reporting a Vulnerability

As this repository contains sensitive conceptual frameworks concerning general intelligence and control systems, we take all potential vulnerabilities (including architectural or theoretical flaws that could lead to misaligned implementations) very seriously.

If you discover a vulnerability, **do not open a public issue.**

Please practice responsible private disclosure by contacting the project author, Eric Lin, directly:
**Contact Email:** eric26752196@gmail.com

When reporting an issue, please include:

* A clear description of the vulnerability or theoretical flaw.
* The potential impact or exploit scenario.
* Any proposed mitigations or structural corrections to the topology.

You can expect an initial response acknowledging the receipt of your report within 72 hours.
