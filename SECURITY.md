# Security Policy

## Supported Versions

Currently, this repository is a documentation-only project. All contents are in the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please do **NOT** create a public issue.

Instead, please send an email to the project maintainers with the details of the vulnerability. We will review the submission and, if verified, work on a fix as quickly as possible. Please allow up to 48 hours for an initial response.

When reporting a vulnerability, please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (if applicable).
- Any potential solutions or mitigations.
