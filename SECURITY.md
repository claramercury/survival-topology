# Security Policy for Survival Topology

## Reporting a Vulnerability

Security is a core component of the Survival Topology architecture. We take all security vulnerabilities in this theoretical control theory framework and its related theoretical implementation seriously.

If you believe you have found a security vulnerability in the Survival Topology documentation or conceptual framework, please **do not open a public issue**. Instead, follow our private responsible disclosure process.

Please report any security vulnerabilities directly to the author, Eric Lin, via email at:
`eric26752196@gmail.com`

When reporting a vulnerability, please provide:

* A detailed description of the vulnerability.
* The specific theoretical components or documentation sections affected.
* (If applicable) Steps to reproduce the conceptual flaw or security issue.
* The potential impact if the vulnerability were exploited.

We aim to acknowledge receipt of vulnerability reports within 72 hours and will work to address verified issues promptly.

Thank you for helping keep the Survival Topology project secure!
