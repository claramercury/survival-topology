# Security Policy for Survival Topology

This document outlines the security policy and vulnerability reporting guidelines for the Survival Topology theoretical framework and its conceptual architecture (the "Wh- Protocol").

## Supported Versions

Currently, the Survival Topology documentation is in its draft phase (Version 1.0). As a conceptual control theory framework, all discussions regarding its security, architectural robustness, and potential vulnerabilities apply to the current main branch documentation.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |

## Reporting a Vulnerability

**DO NOT** create a public issue for any critical security vulnerability or theoretical flaw you identify in the Survival Topology architecture that could pose significant risks if implemented in AGI systems.

To ensure responsible and private disclosure, please report all security concerns directly to the author, Eric Lin, via email at:

**eric26752196@gmail.com**

Please include the following information in your report:

- A description of the vulnerability or architectural flaw.
- The potential impact on the "Wh- Protocol" control layer or "Existential Feedback" systems.
- Any proof-of-concept thoughts or simulations demonstrating the risk.

We will endeavor to respond to your report promptly and coordinate on any necessary adjustments to the framework before they are published.

Thank you for contributing to the safe development of closed-loop AGI systems.
