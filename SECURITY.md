# Security Policy

## Supported Versions

The "Survival Topology" conceptual framework is a theoretical document and does not have software releases. However, the documentation itself and any associated scripts will be maintained for security.

## Reporting a Vulnerability

Security is a primary concern for the Survival Topology project. We mandate **private responsible disclosure** for any vulnerabilities found in the repository or its conceptual architectural models.

**Do NOT open a public issue for security vulnerabilities.**

If you discover a vulnerability, please contact the project author, Eric Lin, directly via email at:
`eric26752196@gmail.com`

Please include the following details in your report:

* A description of the vulnerability and its potential impact.
* Detailed steps to reproduce the vulnerability.
* Any potential fixes or suggestions you might have.

We will acknowledge receipt of your vulnerability report and strive to resolve it promptly while keeping you informed of our progress.
