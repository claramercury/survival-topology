# Security Policy for Survival Topology

Thank you for your interest in the security of the Survival Topology project.

While this repository primarily contains the theoretical framework and documentation for the "Wh- Protocol", we take the integrity and security of our intellectual property and potential implementations seriously.

## Supported Versions

Currently, the primary documentation is under the initial draft version.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |

## Reporting a Vulnerability

We prioritize responsible and private disclosure of any security concerns related to the Survival Topology framework, its mathematical models, or conceptual architecture.

If you discover any security issue, flaw in the conceptual framework that could lead to vulnerabilities if implemented, or repository-related security concerns, please **DO NOT** open a public issue.

Instead, please privately report the vulnerability to the project author, Eric Lin, via email:

* **Email:** [eric26752196@gmail.com](mailto:eric26752196@gmail.com)

Please provide a detailed description of the issue, including potential impact and any steps to reproduce or verify the concern. We will strive to acknowledge your report promptly and work with you to address it securely.
