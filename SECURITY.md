# Security Policy for Survival Topology

Thank you for your interest in the security of the Survival Topology project. As an architectural and conceptual framework for AGI control theory (the "Wh- Protocol"), we take the security implications of these theoretical models seriously.

## Supported Versions

Currently, this repository primarily contains the theoretical documentation (Version 1.0 Draft).

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We strongly believe in private, responsible disclosure for any vulnerabilities or security implications found within the Survival Topology framework or any associated implementations.

**Do not open public issues for security vulnerabilities.**

If you discover a vulnerability, please report it privately to the project author, Eric Lin, via email at:
`eric26752196@gmail.com`

Please include the following in your report:

* A description of the vulnerability.
* The potential impact.
* Steps to reproduce or understand the theoretical vulnerability.
* Any proposed mitigations or fixes.

We will endeavor to respond to your report as quickly as possible.
