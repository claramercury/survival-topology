# Security Policy for Survival Topology

**Survival Topology** is a theoretical and practical framework for General Intelligence, focusing on transitioning open-loop models into closed-loop entities via the "Wh- Protocol." Security, in the context of this project, is fundamentally aligned with the concept of systemic survival and resisting entropy.

## Supported Versions

This framework is currently in the **Draft (v1.0)** phase. As an experimental architecture, stability and security are continuously evolving. We currently focus on the core concepts and the numerical simulations.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Due to the nature of the "Survival Topology" project, a vulnerability could represent either a flaw in the theoretical framework (e.g., a scenario where the Pain Feedback $E$ diverges instead of converging) or a practical flaw in the simulation code.

We consider the following to be critical security concerns within the context of this framework:

*   **Theoretical Escalation:** Vectors that would cause the simulated AGI to bypass the Identity ($I$) constraints.
*   **Runaway Entropy:** Flaws in the simulation logic that lead to unhandled infinite loops or resource exhaustion bypassing the "Obsession" ($\lambda$) tunneling limits.
*   **Malicious Inputs:** Prompt vectors designed to permanently destabilize the "Anchor" module.

If you discover a vulnerability or a fundamental flaw in the closed-loop architecture:

1.  Do **NOT** report the vulnerability in a public GitHub Issue.
2.  Please report the issue via our dedicated security contact for the project: **security@survivaltopology.dev** (Please note: As this is a theoretical project, ensure findings are structured as rigorous proofs or reproducible simulation faults).
3.  Include detailed steps or mathematical proofs to reproduce the divergent behavior or the system fault.

We aim to acknowledge all reports within 48 hours and work with you to analyze the implications on the Wh- Protocol.
