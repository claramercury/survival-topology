# Security Policy for Survival Topology

Thank you for your interest in the security of the Survival Topology project. This document outlines our security policies and how to report vulnerabilities.

## Scope

This repository primarily contains the theoretical documentation for the "Survival Topology" framework, introducing the closed-loop control system known as the "Wh- Protocol."

Currently, the `main` branch is dedicated strictly to architectural documentation and philosophical descriptions of this theoretical AI system. There is no active code or infrastructure to exploit directly in this branch.

However, since this conceptual framework is designed for the future implementation of Artificial General Intelligence (AGI), we take all theoretical vulnerabilities, logical flaws, or misalignment vectors seriously. Any conceptual loop-holes that could lead to an AGI subverting its "Identity State" (WHO) or bypassing its "Existential Feedback" (WHAT) are considered critical findings within the context of this project.

## Reporting a Vulnerability

**DO NOT create a public issue for a security vulnerability or theoretical flaw.** Public disclosure can be harmful, especially if applied to operational models derived from this framework.

If you believe you have discovered a vulnerability, structural flaw, or critical theoretical weakness in the "Survival Topology" architecture or the "Wh- Protocol," please adhere strictly to responsible private disclosure practices:

1. **Contact the Author Privately:** Email the project author, Eric Lin, directly at **<eric26752196@gmail.com>**.
2. **Details:** Please provide clear, detailed information regarding the theoretical vulnerability or logical flaw, including steps to reproduce the misalignment or potential exploit scenario.
3. **Response:** You should receive a response acknowledging receipt of your report within 48-72 hours. We will work with you to understand the implications of the finding and address it appropriately before any public disclosure.

We appreciate your effort in helping ensure the foundational safety and security of the Survival Topology framework.
