# Security Policy for Survival Topology

Thank you for your interest in the security of the Survival Topology framework. As this project deals with a theoretical control theory framework for General Intelligence (the Wh- Protocol), ensuring the integrity and security of its conceptual and practical implementations is of paramount importance.

## Reporting a Vulnerability

If you discover a vulnerability or a security flaw in the Survival Topology documentation, architecture, or any associated scripts, **please do not open a public issue.** Public disclosure could allow malicious actors to exploit the vulnerability before a patch or mitigation is available.

Instead, we follow a private responsible disclosure process. Please report any security findings directly to the author, Eric Lin, by emailing:
**eric26752196@gmail.com**

When reporting, please include the following information:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- (Optional) Any suggested mitigations or fixes.

We take all security reports seriously and will strive to acknowledge your report promptly and provide updates on the resolution.

Thank you for helping keep Survival Topology secure.
