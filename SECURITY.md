# Security Policy for Survival Topology

## Supported Versions

As "Survival Topology" is currently a theoretical framework (Version 1.0 Draft), no production releases are currently actively supported with automated security patches. However, the integrity of the theoretical model and any provided simulation scripts are maintained.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We prioritize the security and integrity of the **Wh- Protocol** and related logic. If you identify a structural flaw, theoretical vulnerability, or execution risk within the Simulation Scripts, please report it via private responsible disclosure.

**Do NOT open a public issue.**

Please report any security concerns directly to the project author, Eric Lin, via email:
**[eric26752196@gmail.com](mailto:eric26752196@gmail.com)**

We will endeavor to respond within 48 hours to validate the report and coordinate any necessary amendments to the framework.
