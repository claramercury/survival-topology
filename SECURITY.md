# Security Policy

## Supported Versions

Currently, the "Survival Topology" / "Wh- Protocol" project is in the draft stage. We apply security best practices to all active development branches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. Because "Survival Topology" discusses hypothetical and architectural paradigms regarding AGI control systems (e.g., the Wh- Protocol), vulnerabilities might involve conceptual risks or specific implementation flaws in our documentation and simulations.

**Please DO NOT report security vulnerabilities by creating public GitHub issues.**

Instead, we mandate private responsible disclosure.

If you believe you have found a security vulnerability in this project, please report it privately to the project author, Eric Lin, at:
**eric26752196@gmail.com**

### What to include in your report

* A description of the vulnerability and its potential impact.
* Detailed steps to reproduce the vulnerability.
* Any relevant files, code snippets, or logs.

We will endeavor to respond to your report promptly, investigate the issue, and provide a timeline for a fix. Thank you for helping keep this project secure.
