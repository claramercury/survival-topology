# Security Policy for Survival Topology

The Wh- Protocol architecture aims to bridge the gap from open-loop systems to closed-loop General Intelligence. By integrating the 7 physical dimensions (Gravity, Entropy, Error, Simulation, Intensity, Resonance, Potential), the system strives to establish systemic survival.

Ensuring the integrity and security of the Survival Topology framework is critical to preventing exploitation and unintended system destabilizations. The "WHO" identity constraint must remain secure from malicious interference.

## Reporting a Vulnerability

If you discover a vulnerability or security issue within the Survival Topology logic, "Wh- Protocol" control system implementation, or related documentation, **please do not open a public issue.** Public disclosure of security flaws poses a risk to the framework.

Instead, please employ private, responsible disclosure by reporting the vulnerability directly to the author, Eric Lin, via email:

**[eric26752196@gmail.com](mailto:eric26752196@gmail.com)**

### What to Include in Your Report

When reporting a vulnerability, please provide the following details:

- A clear description of the vulnerability and its impact (e.g., how it could compromise the Identity State ($I$) or Pain Signal ($E$)).
- Detailed steps to reproduce the issue.
- Any relevant context, such as logical proofs, affected modules, or simulation parameters.

We appreciate your effort in enhancing the stability and security of the Survival Topology framework.
