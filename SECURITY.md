# Security Policy

| ------- | ------------------ |

## Reporting a Vulnerability

We prioritize the security of the Survival Topology framework.

If you discover a security vulnerability or concern within the documentation, conceptual architecture, or implementation, we kindly ask for responsible disclosure.

Please **do not** open public issues for security vulnerabilities. Instead, report them privately to the author:
**Eric Lin: eric26752196@gmail.com**

We will respond to all reports and work with you to understand and mitigate the issue.
