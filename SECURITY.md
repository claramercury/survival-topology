# Security Policy for Survival Topology

## Supported Versions

Currently, the master branch of this repository is supported with security updates.

## Reporting a Vulnerability

Security is a primary priority for the Survival Topology project.
If you discover any security vulnerability in this documentation or associated artifacts, **do not open a public issue.**
Public disclosure of security vulnerabilities can put users and the project at risk.

Instead, please practice responsible disclosure by sending an email directly to the project author, Eric Lin, at:
**eric26752196@gmail.com**

Please include:

* A clear description of the vulnerability.
* Steps to reproduce the issue.
* Any potential impact or suggestions for remediation.

We will endeavor to respond to your report as quickly as possible and will keep you informed of the progress in resolving the issue. Thank you for helping keep Survival Topology secure.
