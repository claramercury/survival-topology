# Security Policy

## Supported Versions

The Survival Topology project is primarily a conceptual control theory framework and documentation repository. Security support applies to the current main branch and any published theoretical implementations.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a critical aspect of the Wh- Protocol and the Survival Topology architecture. Due to the sensitive nature of systemic vulnerabilities or potential conceptual bypasses in the control feedback loops, **we require responsible private disclosure.**

**Do not open public issues or pull requests for security vulnerabilities.**

If you discover any security issue, please report it privately to the project author, Eric Lin, by emailing:
**eric26752196@gmail.com**

Please provide detailed information about the vulnerability, the potential impact on the "Identity State" or feedback loops, and steps to reproduce or exploit it. We will investigate all reports promptly and work with you to ensure a coordinated and secure resolution.
