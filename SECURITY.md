# Security Policy for Survival Topology

## Supported Versions

At this time, only the current draft of Survival Topology (main branch) and the latest Bookhook Android Application are supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project very seriously. Due to the conceptual nature of the Survival Topology and the private implementations associated with the Wh- Protocol, **all vulnerabilities must be disclosed privately**.

**DO NOT open public issues for security vulnerabilities.**

If you discover a vulnerability, please immediately contact the project author, Eric Lin, directly via email at:
**eric26752196@gmail.com**

Please provide the following details in your email:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Any suggested mitigations.

You should receive a response within 48 hours acknowledging receipt of the vulnerability report.
