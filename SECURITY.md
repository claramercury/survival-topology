# Security Policy

## Supported Versions

The "Survival Topology" framework is currently in Draft (Version 1.0).

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As the guardian of the "Survival Topology" conceptual framework, we take security very seriously.

If you discover any security vulnerability, flaw in the control theory framework, or potential risk associated with the mathematical definitions in this repository, please **do not open a public issue**. Instead, follow the responsible disclosure process below:

1. Send an email to the project author, Eric Lin, at <eric26752196@gmail.com>.
2. In your email, clearly describe the vulnerability, the potential impact, and provide steps to reproduce or theoretically validate the issue.
3. We will review your submission and acknowledge receipt.

Public disclosure of vulnerabilities without prior coordination puts the project and its theoretical integrity at risk. Please adhere to this private disclosure process.
