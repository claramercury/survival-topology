# Security Policy for Survival Topology

## Supported Versions

Since this project primarily consists of the theoretical "Survival Topology" and "Wh- Protocol" documentation, updates are made directly to the `main` branch.

| Branch | Supported |
|--------|-----------|
| `main` | ✅ Yes     |

*Note: For the Bookhook Android application, please refer to its specific branch and documentation.*

## Reporting a Vulnerability

We take the security of this conceptual framework and its repository seriously. Even though this branch (`main`) is predominantly theoretical markdown documentation, it serves as the foundation for the "Wh- Protocol".

**Do NOT create public issues for security vulnerabilities.**

If you discover a vulnerability or security-related risk (e.g., conceptual flaws that could lead to unsafe implementations, repository misconfigurations, or other security concerns), please report it privately:

1. **Private Vulnerability Reporting**: Use GitHub's [Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) feature on this repository.
2. In your report, please include:
   - A clear description of the vulnerability or conceptual security flaw.
   - The impact it could have on the theoretical integrity of the "Wh- Protocol" or the repository.
   - Suggested steps for mitigation or correction.

We will review reports promptly and collaborate privately on any necessary updates.

## Scope

Security enhancements targeting `main` focus on conceptual architectural security principles, repository configurations, and documentation improvements. Code-level vulnerabilities for practical implementations should be addressed in their respective branches (e.g., the Android application branch).
