# Security Policy for Survival Topology

## Supported Versions

The Survival Topology project is primarily a theoretical framework and documentation repository. Security updates and reviews will be provided for the latest draft.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As this repository contains conceptual control theory frameworks and architectural descriptions for an Artificial General Intelligence (AGI), we take security vulnerabilities related to these concepts—as well as standard repository security—very seriously.

### Private Responsible Disclosure

**Do not open public issues for security vulnerabilities.**

If you discover any security vulnerabilities, please responsibly disclose them directly to the author, Eric Lin, via email at:
**eric26752196@gmail.com**

Please include the following details in your report:

* A description of the vulnerability.
* The potential impact on the conceptual framework or project infrastructure.
* Suggested mitigation or fix, if applicable.

You can expect an initial acknowledgment within 48 hours.

We appreciate your effort in helping us maintain the security and integrity of the Wh- Protocol and the Survival Topology project.
