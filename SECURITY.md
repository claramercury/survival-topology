## Reporting a Vulnerability

We take the security of the Survival Topology framework and its conceptual implementations very seriously.

If you discover a security vulnerability within this repository or related to the Wh- Protocol theoretical framework, please do **NOT** open a public issue. Exposing vulnerabilities publicly can put users at risk.

Instead, please responsibly disclose the vulnerability privately by contacting the author, Eric Lin, via email:

📧 **Contact Email:** <eric26752196@gmail.com>

### What to include in your report

* A description of the vulnerability and its potential impact.
* Detailed steps to reproduce the issue.
* (Optional) Any proof-of-concept code or conceptual exploitation scenarios.

We will acknowledge receipt of your vulnerability report and strive to provide a resolution as quickly as possible.
