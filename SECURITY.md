# Security Policy for Survival Topology

## Supported Versions

Currently, the master version of the documentation and concepts in the `main` branch is supported for security updates.

## Reporting a Vulnerability

We take the security of the Survival Topology architecture and its associated concepts very seriously. If you discover a vulnerability or security issue, please follow our private responsible disclosure process.

### Responsible Disclosure

**DO NOT** open public issues, create pull requests, or otherwise publicly disclose vulnerabilities you find. This ensures that potential attackers cannot exploit the vulnerability before a fix is ready.

Please report any security vulnerabilities directly to the project author:

* **Author:** Eric Lin
* **Contact:** eric26752196@gmail.com

### What to Include

When reporting an issue, please provide as much context as possible, including:

* A detailed description of the vulnerability.
* Steps to reproduce the issue.
* Any potential impact or risk associated with the vulnerability.

The author will endeavor to respond to your report promptly and coordinate a fix.
