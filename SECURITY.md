# Security Policy for Survival Topology

## Supported Versions

Currently, the following versions of the "Survival Topology" documentation, the Wh- Protocol framework, and associated simulation code are supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is critical to the development of the "Survival Topology" architecture and the Wh- Protocol framework. If you discover a security vulnerability in the theoretical models, the simulation code, or any associated components within this repository, we ask that you practice responsible disclosure.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using one of the following private channels:

1. **GitHub Private Vulnerability Reporting:** Navigate to the "Security" tab of this repository and click "Report a vulnerability" to securely send us details.
2. **Direct Private Contact:** If you are unable to use GitHub's private reporting, please reach out to the maintainer directly via secure private messaging channels established by the repository owner (e.g. direct contact to Eric Lin).

When reporting a vulnerability, please include:

* A detailed description of the vulnerability and its potential impact on the Wh- Protocol simulation or related components.
* Step-by-step instructions to reproduce the issue.
* Any potential mitigation or fixes you suggest.

We will review the submission as quickly as possible and provide an estimated timeline for resolution. All validated security issues will be addressed promptly.
