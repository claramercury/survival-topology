# Security Policy

## Supported Versions

The "Survival Topology" project is primarily a theoretical framework and documentation project. At this time, only the latest iteration on the main branch is actively maintained.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our conceptual frameworks and theoretical documentation seriously.

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, we mandate private responsible disclosure for all vulnerabilities. If you discover a security vulnerability or have a security-related concern regarding this project, please report it via email to the project author, Eric Lin, at:

**[eric26752196@gmail.com](mailto:eric26752196@gmail.com)**

Please include the following in your report:

* A description of the vulnerability.
* Steps to reproduce the issue (if applicable).
* Any potential impact or theoretical implications.

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your message.
