# Security Policy

## Supported Versions

Currently, the theoretical framework and documentation for **Survival Topology** are continuously evolving. We provide security and conceptual support for the latest iteration of the framework.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As this repository contains the foundational theoretical documentation ("Survival Topology") and control theory frameworks (the "Wh- Protocol"), vulnerabilities here might pertain to conceptual architectural flaws, logical loops, or systemic risks in the theoretical model, rather than typical code exploits. However, we take all reported vulnerabilities—both conceptual and practical—seriously.

**Do not open a public issue for a vulnerability.** To protect the integrity of the framework and prevent potential exploitation of conceptual vulnerabilities before they are addressed, we require all security findings to be reported privately.

Please report any security concerns, conceptual vulnerabilities, or architectural risks using one of the following methods:

1. **Private Vulnerability Reporting**: Use GitHub's native private vulnerability reporting feature on this repository.
2. **Direct Email**: Contact Eric Lin directly at `eric26752196@gmail.com` with the subject line `[SECURITY] Survival Topology Vulnerability Report`.

### What to Include

When reporting a vulnerability, please provide:

* A detailed description of the vulnerability or architectural flaw.
* The specific section of the "Wh- Protocol" or "Survival Topology" framework affected.
* Potential impact or consequences if the vulnerability were exploited or practically implemented.
* Any proposed mitigations or theoretical corrections.

### Response Timeline

We will acknowledge receipt of your vulnerability report within 72 hours and provide an estimated timeline for addressing the issue. We are committed to a responsible disclosure process and will coordinate with you to publish any necessary advisories or theoretical revisions.
