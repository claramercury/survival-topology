# Security Policy

## Supported Versions

The "Survival Topology" project is primarily a theoretical framework and documentation repository. Security updates apply to the conceptual architecture presented in the current main branch documentation.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| Drafts  | :x:                |

## Reporting a Vulnerability

We prioritize the security of the Wh- Protocol framework. If you discover a vulnerability or security flaw in the conceptual architecture or implementation specifications, please disclose it responsibly.

**Do not open a public issue.**

Instead, please report vulnerabilities privately by emailing the author directly:
**Contact:** Eric Lin
**Email:** eric26752196@gmail.com

When reporting, please include:

- A detailed description of the vulnerability.
- Theoretical or practical steps to reproduce the issue.
- Potential impact on the system's "Identity State" or closed-loop control mechanisms.

We will endeavor to respond to your report within 48 hours and work with you to understand and resolve the issue before public disclosure.
