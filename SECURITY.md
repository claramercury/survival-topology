# Security Policy

## Supported Versions

Currently, the master branch of "Survival Topology" is the only branch receiving security updates.

## Reporting a Vulnerability

Security is a high priority for the "Survival Topology" project.

If you have discovered a vulnerability, **do not** open a public issue. Instead, please report it privately.

To report a vulnerability or any security-related concern, please contact the author via email:
**eric26752196@gmail.com**

Please provide detailed information about the vulnerability, including:

- A description of the issue and its impact.
- Steps to reproduce the vulnerability.
- Any potential mitigation or fix you might suggest.

We will acknowledge your report as soon as possible and work to resolve the issue promptly while maintaining responsible disclosure practices.
