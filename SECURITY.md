# Security Policy for Survival Topology

## Supported Versions

The Survival Topology project is currently a theoretical documentation framework with an accompanying Python simulation. We only support security updates for the current draft version:

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As this project primarily consists of theoretical documentation on Artificial General Intelligence (AGI) and a single simulation script, traditional security vulnerabilities (like XSS or SQL injection) are unlikely. However, we take the security of the framework's mathematical representations and any embedded Python code seriously.

If you discover a vulnerability or a significant flaw that could lead to unintended consequences in the proposed architecture (such as an exploit in the Wh- Protocol's feedback loop, or malicious injection vectors in the Python script's theoretical execution), please report it to us.

**Do not open up a GitHub issue if the bug is a security vulnerability in the simulation script.**

Please email the author directly at **security@survivaltopology.com** (Placeholder for the actual author's contact if this project had one; since this is a draft, please open a private security advisory on GitHub if possible).

Please provide the following details:
- A clear description of the vulnerability.
- Steps to reproduce the issue (if applicable to the Python script).
- Potential impact on the proposed AGI architecture.

We will acknowledge receipt of your vulnerability report within 72 hours and strive to provide a timeline for a fix or an update to the theoretical framework.
