# Security Policy

## Supported Versions

Currently, the main branch of this project is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please report it privately.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to `security@example.com` or create a private vulnerability report via GitHub.

You should receive a response within 48 hours. If the issue is confirmed, we will release a patch as soon as possible.
