# Security Policy

## Supported Versions

The following versions of the project are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities by using GitHub's private vulnerability reporting feature for this repository, or by contacting the repository maintainers directly.

Do **not** open a public issue for security vulnerabilities.
