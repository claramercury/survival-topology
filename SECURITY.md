# Security Policy for Survival Topology

**Author:** Eric Lin

Thank you for helping to improve the security of the Survival Topology documentation project and its conceptual control theory framework (the "Wh- Protocol"). We take the security of this project and its philosophical concepts seriously.

## Reporting a Vulnerability

We mandate private responsible disclosure for all security vulnerabilities. **Do not open a public issue** or disclose vulnerability details in public pull requests, as this could expose sensitive information or conceptual flaws.

If you believe you have found a security vulnerability or critical flaw in the project, please report it privately.

**Contact:**
Please email the author, Eric Lin, directly at: [eric26752196@gmail.com](mailto:eric26752196@gmail.com)

**What to include in your report:**

* A descriptive summary of the vulnerability.
* The specific section or component affected.
* Step-by-step instructions to reproduce the issue.
* A proof-of-concept, if available.
* An assessment of the potential impact.

We will acknowledge receipt of your vulnerability report as soon as possible and strive to address verified issues promptly.

Thank you for your responsible disclosure and for contributing to the integrity of Survival Topology.
