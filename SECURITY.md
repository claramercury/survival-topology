# Security Policy for Survival Topology

## Supported Versions

The Survival Topology is currently a conceptual framework documentation project. Security updates are primarily applied to the `main` branch, which represents the latest state of the theoretical documentation.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As this repository contains sensitive conceptual formulations and architectural principles, we take the security of this documentation very seriously. If you discover any security vulnerabilities, logical flaws, or risks within the "Survival Topology" framework or its associated infrastructure, **do not open a public issue.**

Instead, please practice private responsible disclosure by adhering to the following process:

1. **Private Contact:** Directly email the author, Eric Lin, at `eric26752196@gmail.com`.
2. **Details:** Include a clear description of the vulnerability, the potential impact, and any relevant steps to reproduce or verify the issue.
3. **Response Time:** We will endeavor to acknowledge receipt of your vulnerability report within 48 hours and provide an estimated timeline for addressing the issue.

We appreciate your cooperation in keeping this project secure. Publicly disclosing vulnerabilities before they are resolved could unnecessarily expose the system.
