# Security Policy

## Supported Versions

The following versions of the Survival Topology framework are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As the Survival Topology project is currently a documentation-focused framework, active code execution vulnerabilities are unlikely. However, if you discover any security concerns, conceptual flaws in the Wh- Protocol, or potential risks related to its implementation, please follow this process.

Please report security issues by creating a draft security advisory in this repository. Do not disclose potential vulnerabilities or theoretical risks in public issues or pull requests.

We will acknowledge your report within 48 hours and provide updates on the status of our review.
