# Security Policy

## Supported Versions

The Survival Topology conceptual framework and associated implementations are currently in draft.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a critical aspect of the Survival Topology framework. We appreciate your efforts to responsibly disclose any theoretical flaws or code vulnerabilities you may find.

**Do not open a public issue.** To ensure the safety of the project and its users, please report all security vulnerabilities privately.

Please contact the author, Eric Lin, directly via email at:
**<eric26752196@gmail.com>**

When reporting, please include:

- A description of the vulnerability.
- Steps to reproduce, if applicable.
- Any potential impact on the system or conceptual framework.

You should receive a response within 48 hours. Thank you for helping keep the Survival Topology project secure.
