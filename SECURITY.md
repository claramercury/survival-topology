# Security Policy for Survival Topology

Thank you for your interest in the security of the Survival Topology project. This document outlines our security policies and responsible disclosure guidelines.

## Scope

This repository primarily contains the theoretical framework and documentation for the "Wh- Protocol" and Survival Topology concepts. While it does not host an active software application, any vulnerabilities or issues related to the project's infrastructure, hosting, or conceptual security flaws are considered in scope.

## Reporting a Vulnerability

If you discover a security vulnerability or have a security-related concern regarding this project, please follow these steps for responsible disclosure:

1. **Do not open a public issue.** Exposing potential vulnerabilities in public forums can put the project and its users at risk.
2. **Contact the author directly.** Please report any security findings via email to Eric Lin at **eric26752196@gmail.com**.
3. **Include details.** Provide a clear description of the vulnerability, potential impact, and steps to reproduce if applicable.

We take security seriously and will work to address reported issues as quickly as possible.

## Conceptual Vulnerabilities

Given the nature of this project as a Control Theory Framework for General Intelligence, we are also open to discussions regarding theoretical security flaws, alignment risks, or vulnerabilities within the proposed "Wh- Protocol" itself. Please use the same reporting mechanism (email) for these philosophical and architectural security discussions.
