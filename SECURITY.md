## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in this project, please report it to us as soon as possible.
You can email us at security@example.com (replace with real email if available) or use GitHub Security Advisories.

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

We will try to respond to all reports within 48 hours.
