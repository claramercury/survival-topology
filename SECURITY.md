# Security Policy for Survival Topology

The Survival Topology project is committed to maintaining the security and integrity of its conceptual control theory framework ("Wh- Protocol") and any associated code or documentation.

## Supported Versions

Currently, the primary documentation and framework are maintained on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take all security issues and vulnerabilities seriously. If you discover a security issue within the Survival Topology framework, its mathematical models, or any associated implementation, please report it to us privately.

**Do not open a public issue for security vulnerabilities.** Publicly disclosing a vulnerability can put the project and its users at risk.

Instead, please practice private responsible disclosure by contacting the project author directly:

- **Email:** [eric26752196@gmail.com](mailto:eric26752196@gmail.com)

Please provide a detailed description of the vulnerability, including:

- The scope of the issue (e.g., specific theoretical flaw, code vulnerability in provided scripts).
- Steps to reproduce or verify the issue.
- The potential impact.
- Any suggested mitigations or fixes.

We will review your report, acknowledge its receipt, and work on addressing the issue appropriately.
