# Security Policy for Survival Topology

## Supported Versions

Currently, the theoretical framework and documentation for **Survival Topology: A Control Theory Framework for General Intelligence** are supported. The "Wh- Protocol" control layer concepts are considered active.

## Reporting a Vulnerability

Security is a fundamental component of the "Survival Topology" architecture and we take potential risks in this conceptual framework very seriously.

If you discover a vulnerability or a critical flaw in the theoretical security model of this project, **do not** open a public issue. We adhere to responsible private disclosure practices to ensure the integrity of the framework.

Please report any security issues privately by emailing the author, Eric Lin, directly at **eric26752196@gmail.com**.

When reporting an issue, please include:

* A detailed description of the vulnerability or flaw in the framework.
* Steps or theoretical constructs required to reproduce the issue.
* The potential impact on the closed-loop system or existential feedback mechanisms.
* Any potential mitigations or solutions you have identified.

You should receive a response within 48 hours acknowledging receipt of the report. We will then review the issue, coordinate a fix, and define a timeline for a patch or update to the documentation.
