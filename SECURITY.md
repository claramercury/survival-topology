# Security Policy for Survival Topology

## Reporting a Vulnerability

We take the security of this project seriously. Because the Survival Topology project serves as the foundational documentation for a generalized framework, maintaining its integrity is paramount.

If you believe you have found a security vulnerability in this project, **please do not report it in a public issue.**

Instead, please privately report it directly to the project author, Eric Lin, via email at:
**eric26752196@gmail.com**

### What to Include

When reporting a potential vulnerability, please include:

- A detailed description of the vulnerability.
- Steps to reproduce the issue (if applicable).
- The potential impact.
- Any suggestions for remediation.

### Response Time

You should receive a response acknowledging receipt of your report within a reasonable timeframe (typically 48 hours). Please allow time for investigation and remediation before publicly disclosing the vulnerability.
