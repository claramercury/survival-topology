# Security Policy for Survival Topology

As the Survival Topology framework introduces a closed-loop control system for
Artificial General Intelligence (AGI) based on the "Wh- Protocol," we take the
security and stability of these theoretical and mathematical models seriously.
Due to the foundational nature of this architecture, identifying conceptual
vulnerabilities or logic flaws in the control loops is critical.

## Supported Versions

Since this repository primarily hosts the conceptual framework and mathematical
proofs for the Survival Topology model, we currently support the following
versions for security and logic assessments:

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We prioritize the responsible disclosure of any conceptual, mathematical, or
systemic vulnerabilities identified within the Survival Topology framework or
its simulations.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via **GitHub's private vulnerability reporting**
feature if available for this repository, or contact the maintainers privately.

When reporting a vulnerability, please include:

* A detailed description of the flaw within the Wh- Protocol (e.g., recursive
  loop escapes, failure in the "Pain" feedback variable $E$, etc.).
* Theoretical or mathematical proof of the exploit.
* Suggested mitigations or corrections to the control loops.

We will acknowledge receipt of your vulnerability report within 72 hours and
provide a timeline for our theoretical analysis and framework updates.
