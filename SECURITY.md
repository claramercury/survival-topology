# Security Policy

## Supported Versions

Currently, the "Survival Topology" project is mostly documentation and theory on the "Wh- Protocol" framework. There is no code release, so only the `main` branch documentation and design concepts are actively updated.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our framework concepts seriously. If you discover a vulnerability or security-related flaw in our theoretical models, algorithms, or documentation, we appreciate your help in responsibly disclosing it to us.

**Do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report them directly via email to the project author, Eric Lin, at:
**[eric26752196@gmail.com](mailto:eric26752196@gmail.com)**

Please include:

- A description of the vulnerability or conceptual flaw.
- Instructions on how to reproduce or conceptualize the issue.
- Potential impact and, if possible, suggestions for mitigation.

We will endeavor to respond within a timely manner and address the issue before it is made public.
