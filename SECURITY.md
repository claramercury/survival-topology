# Security Policy for Survival Topology

This document outlines the security policies for the "Survival Topology" control theory framework project.

## Scope

This policy applies specifically to the documentation and theoretical models related to the "Survival Topology" framework in this repository (`main` branch).
While this project focuses heavily on theoretical concepts related to General Intelligence and closed-loop control systems, maintaining the security and integrity of these theories and associated files is critical.

## Reporting a Vulnerability

Security is a high priority. However, because vulnerabilities may have conceptual or architectural implications, **do not open public issues or pull requests for security vulnerabilities.**

If you discover a security vulnerability or a theoretical flaw that poses a security risk, we mandate **private responsible disclosure**.

Please report any findings privately via email to the author, Eric Lin, at:
**eric26752196@gmail.com**

When reporting, please include:

* A clear description of the vulnerability or flaw.
* Steps to reproduce the issue (if applicable).
* Any potential impact or risk associated with the finding.

We will review reports promptly and collaborate with you on a resolution before any public disclosure.

## Best Practices

* Ensure all conceptual proposals adhere to robust theoretical principles to avoid introducing logic flaws.
* Do not include sensitive data or proprietary configurations in any examples or documentation.
* Modifications to the documentation should be reviewed to ensure they align with the project's security and theoretical goals.
