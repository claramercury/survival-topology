# Security Policy for Survival Topology

**Scope:**
This security policy applies to the Survival Topology documentation repository. Since this repository currently consists entirely of theoretical and architectural markdown documentation for the "Wh- Protocol," security concerns are generally related to the conceptual integrity of the framework or potential future implementations of these theories.

If you identify a potential security risk in the concepts described—such as ways the theoretical framework could be exploited in an AGI implementation, or if you discover vulnerabilities in any supplemental scripts (e.g., simulation code)—we strongly encourage responsible disclosure.

**Reporting a Vulnerability:**
To ensure the safety of potential future systems based on this architecture, please **do not open public issues** for security vulnerabilities. Instead, practice private responsible disclosure by contacting the project author directly.

Please email your findings, along with a detailed description of the potential exploit and steps to reproduce (if applicable), to:
**Eric Lin: eric26752196@gmail.com**

We appreciate your effort in helping to secure the Survival Topology framework and will review all reports as quickly as possible.
