# Security Policy

## Supported Versions

Currently, the "Survival Topology" project is in draft form (Version 1.0) and focuses on the theoretical framework for Artificial General Intelligence.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |

## Reporting a Vulnerability

Security is a primary concern for the Survival Topology framework, as any vulnerabilities in the "Wh- Protocol" could theoretically be exploited in future AGI systems.

If you believe you have found a security vulnerability or a conceptual flaw that could lead to unauthorized system states or open-loop failures, **do not open a public issue.**

Instead, please practice private responsible disclosure by emailing the author, Eric Lin, directly at:
**eric26752196@gmail.com**

Please include the following in your report:

* A clear description of the vulnerability.
* The potential impact of the vulnerability.
* Steps to reproduce the vulnerability (if applicable).
* Any proposed fixes or mitigations.

We will endeavor to respond to your report promptly. Thank you for helping to secure the Survival Topology framework.
