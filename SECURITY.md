# Security Policy

## Supported Versions

The Survival Topology project provides conceptual frameworks, documentation, and the theoretical foundation for the Wh- Protocol. Updates are provided on the latest version of the main branch. Currently, there are no prior major versions to track.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As this project focuses heavily on the philosophical implications and architectural security ("Survival Topology") of AI systems, we consider vulnerabilities related to prompt injection bypassing core constraints or logic flaws leading to unconstrained state deviation as valid concerns.

We take all security vulnerabilities seriously, but please DO NOT report security vulnerabilities via public issues or pull requests.

To report a vulnerability privately, please email the author directly:
**Eric Lin: eric26752196@gmail.com**

Please include:

* A detailed description of the vulnerability and its potential impact.
* Steps to reproduce the issue.
* If applicable, a proof of concept.

The maintainer will acknowledge receipt of your vulnerability report and will strive to send you regular updates about the progress of the investigation and the development of a fix or mitigation strategy.
