# Security Policy

## Supported Versions

Currently, the "Survival Topology" project is conceptually under active development. The latest stable conceptual revisions in the `main` branch are continuously supported.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As this repository currently hosts the "Survival Topology" theoretical documentation and control theory framework, the primary security concerns involve severe structural misrepresentations or conceptual vulnerabilities that could jeopardize the integrity of the proposed "Wh- Protocol."

If you discover a vulnerability or security risk within the theoretical framework or associated documentation of this project, please **do not open a public issue.**

To protect the conceptual integrity and ensure proper mitigation, we ask that all security-related issues be reported via private responsible disclosure.

### Contact Information

Please report any critical security issues, conceptual vulnerabilities, or architectural concerns directly to the project author, Eric Lin, via email:

* **Email:** [eric26752196@gmail.com](mailto:eric26752196@gmail.com)

### What to Include in Your Report

When reporting a vulnerability, please include the following details:

1. **Summary:** A brief description of the vulnerability.
2. **Severity:** Your assessment of the severity (e.g., Critical, High, Medium).
3. **Details:** A detailed explanation of the issue and its potential impact on the framework.
4. **Proof of Concept (Optional):** Steps to reproduce or conceptual proof of the vulnerability.

We will review all reports and aim to acknowledge receipt within 48 hours. Thank you for your commitment to the security and integrity of the "Survival Topology" project.
