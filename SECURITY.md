# Security Policy for Survival Topology

## Reporting a Vulnerability

Security is a fundamental concept in the Survival Topology architecture. We take vulnerabilities in our control theory framework and documentation seriously.

If you discover a vulnerability or security issue within the Survival Topology project, the "Wh- Protocol" documentation, or any related conceptual models, please **do not open a public issue**. Public disclosure may expose sensitive conceptual flaws before they can be addressed.

Instead, we mandate a private, responsible disclosure process. Please report any security vulnerabilities directly via email to the author:

**Eric Lin**
Email: `eric26752196@gmail.com`

When reporting, please include:

- A detailed description of the vulnerability.
- Steps to reproduce or understand the conceptual flaw.
- Any potential impact on the proposed closed-loop system or existential feedback mechanisms.

We will review the report and respond as soon as possible to discuss mitigation and resolution. Thank you for helping to secure the Survival Topology framework.
