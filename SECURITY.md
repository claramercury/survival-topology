# Security Policy for Survival Topology

The "Survival Topology" project prioritizes the security of its architectural concepts and theoretical frameworks. We appreciate your efforts to responsibly disclose any potential security vulnerabilities you identify.

## Supported Versions

Currently, the master branch of the "Survival Topology" documentation is the only supported version for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |

## Vulnerability Reporting

If you believe you have found a security vulnerability in the "Survival Topology" framework or its associated documentation, please follow our private responsible disclosure process.

**Do not open a public issue.** Exposing vulnerabilities publicly before they are addressed can pose a risk to the project's integrity.

### How to Report

Please report any critical security issues directly to the author, Eric Lin, via email:

* **Email:** <eric26752196@gmail.com>

In your email, please include:

1. A clear description of the vulnerability.
2. Steps to reproduce the issue.
3. The potential impact of the vulnerability on the project's theoretical framework or infrastructure.
4. Any potential fixes or mitigations you can suggest.

We will endeavor to respond to your report promptly and will work with you to address the issue securely.

Thank you for helping keep the "Survival Topology" project secure.
