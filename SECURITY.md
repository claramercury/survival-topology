# Security Policy

## Supported Versions

Currently, the master version of the documentation and conceptual frameworks on the `main` branch is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As this repository contains a conceptual framework ("Survival Topology") and a theoretical control theory implementation ("Wh- Protocol"), vulnerabilities here are typically architectural flaws or misrepresentations that could lead to unintended cognitive modeling outcomes if implemented in actual intelligent systems.

**Do NOT open a public issue for security-related flaws.**

If you discover a potential vulnerability, architectural flaw, or critical security weakness in the concepts or documentation presented here, please disclose it responsibly and privately by contacting the author, Eric Lin, directly via email at:

**<eric26752196@gmail.com>**

Please provide detailed information in your report, including:

* A description of the theoretical vulnerability or flaw.
* Steps to reproduce or understand the conceptual issue.
* Potential impacts on any systems attempting to implement this framework.
* Any proposed mitigations or corrections to the framework.

We will endeavor to respond to your report promptly.
