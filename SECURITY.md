# Security Policy

## Supported Versions

Currently, only the main branch of the "Survival Topology" conceptual framework is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our framework and its associated components seriously. If you believe you have found a security vulnerability in the "Survival Topology" project, we encourage you to let us know immediately. We will investigate all legitimate reports and do our best to quickly fix the problem.

### Private Responsible Disclosure

**Do not open a public issue.**

To report a vulnerability or a security concern, please send an email directly to the project author, Eric Lin, at:
**eric26752196@gmail.com**

Please provide the following details in your email:

* A description of the vulnerability and its potential impact.
* Detailed steps to reproduce the vulnerability.
* Any proof-of-concept (PoC) code or scripts, if applicable.

We ask that you allow us reasonable time to investigate and mitigate the issue before sharing any information publicly. We will try to respond to your report within 48 hours.
