# Security Policy

## Supported Versions

The 'Survival Topology' project focuses on establishing a closed-loop control system framework for General Intelligence. Security principles discussed herein are relevant to the theoretical architecture.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a fundamental component of the 'Wh- Protocol' and the Survival Topology architecture. If you identify a vulnerability in this project or its theoretical framework that could compromise the integrity of the proposed closed-loop control system, we urge you to report it.

### Private Responsible Disclosure

We take security seriously and ask that you disclose vulnerabilities **privately and responsibly**.

Please **do not** report security vulnerabilities via public GitHub issues or discussions.

To report a vulnerability, please email the project author directly:
**Contact:** Eric Lin
**Email:** `eric26752196@gmail.com`

Please include the following information in your report:

* A detailed description of the vulnerability.
* Steps to reproduce or understand the vulnerability (especially in the context of the conceptual framework).
* Any potential impact on the system's "Identity State" or "Pain" feedback mechanisms.
* Suggested mitigation or fix, if applicable.

We will endeavor to respond to your report promptly.
