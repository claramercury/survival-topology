# Security Policy for Survival Topology

## Supported Versions

The following versions of the Survival Topology project are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of the Survival Topology framework and the theoretical "Wh- Protocol" seriously.

If you believe you have found a security vulnerability in our conceptual architecture or in any associated documentation, please DO NOT create a public issue or pull request.

Instead, please privately report the vulnerability to the project author, Eric Lin, by emailing **eric26752196@gmail.com**.

Please include the following in your report:

- A detailed description of the vulnerability.
- Any potential impact or exploitation vectors.
- A proposed fix, if known.

We aim to respond to all security reports within 48 hours and will coordinate a public disclosure once the issue has been addressed.
