# Security Policy for Survival Topology

## Supported Versions

The **Survival Topology** documentation project is actively maintained on the `main` branch. This branch contains theoretical architectures and control theory frameworks. Security enhancements for this branch should focus on conceptual architectural security principles and documentation integrity.

## Reporting a Vulnerability

We take the security and integrity of our theoretical frameworks and related implementations seriously. If you discover a vulnerability in the documentation or associated applications, please use **private responsible disclosure**.

**Do not open public issues for security vulnerabilities.**

Instead, please report security vulnerabilities directly to the maintainers using **GitHub's Private Vulnerability Reporting** feature. This ensures that the vulnerability can be safely evaluated and resolved before any details are made public.

### Reporting Process

1. Go to the "Security" tab of this repository.
2. Select "Advisories" and click on "Report a vulnerability".
3. Provide a clear description of the issue, including the potential impact and any steps to reproduce or verify the vulnerability.
4. The project maintainers will review the report and coordinate with you on the fix and disclosure timeline.

We appreciate your effort to keep this project secure!
