## Reporting a Vulnerability

We take the security of our conceptual architecture and associated implementations very seriously. If you discover a vulnerability or security flaw, please report it via private responsible disclosure.

**Please DO NOT open a public issue.**

To report a vulnerability or discuss potential security flaws in the Wh- Protocol, please contact the author directly via email:

* **Email:** eric26752196@gmail.com

Please provide a detailed description of the vulnerability, including steps to reproduce it or the specific theoretical flaw. We will try to respond to all reports within a reasonable timeframe.
