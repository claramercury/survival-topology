# Security Policy

## Supported Versions

Currently, the theoretical framework documented in the "Survival Topology" project is the only version maintained. As this repository primarily contains conceptual and philosophical documentation regarding AGI architectures, security vulnerabilities do not impact traditional application deployment architectures.

However, any vulnerability in the *theory* that could allow an instantiated implementation to cause harm is considered a priority.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |

## Reporting a Vulnerability

**DO NOT** create a public issue to report a security vulnerability or theoretical risk in the Survival Topology framework.

We strongly urge all researchers and developers to practice **private responsible disclosure**.

To report a vulnerability:

1. Email the author, Eric Lin, directly at `eric26752196@gmail.com`.
2. Include "SECURITY VULNERABILITY" in the subject line.
3. Describe the vulnerability, its potential impact, and provide any mathematical proofs or conceptual attacks that exploit the Wh- Protocol.

You should receive a response within 48 hours. If the vulnerability is verified, we will work with you privately to develop a patch or conceptual addendum before updating the public repository.
