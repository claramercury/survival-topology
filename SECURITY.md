# Security Policy for Survival Topology

**Survival Topology** is a conceptual control theory framework for General Intelligence, authored by Eric Lin.

While this main branch primarily hosts theoretical documentation and conceptual architecture rather than executable application code, we take the security of this conceptual framework and any associated systems seriously.

## Supported Versions

Currently, this repository only hosts documentation. Security updates primarily focus on the integrity and safety of the conceptual models, architectural proposals, and documentation contents.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We prioritize the security of our conceptual frameworks and any future implementations. We strongly encourage the private, responsible disclosure of any identified security vulnerabilities or conceptual flaws that could lead to security risks if implemented.

**Do NOT open a public issue for security vulnerabilities.**

To report a vulnerability, please contact the author privately:

- **Email:** eric26752196@gmail.com

Please include the following information in your report:

- A detailed description of the vulnerability or conceptual flaw.
- If applicable, the context within the "Survival Topology" architecture where this vulnerability exists.
- Any potential impact or exploitation scenarios.

We will endeavor to respond to your report promptly, verify the issue, and coordinate on a solution or documentation update before public disclosure.

Thank you for helping to keep our systems and concepts secure.
