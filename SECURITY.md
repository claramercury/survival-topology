# Security Policy for Survival Topology

## Supported Versions

The **Survival Topology** project is currently a theoretical framework and documentation repository. As such, only the latest version on the `main` branch is actively supported for security updates and conceptual improvements.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

As an architecture focused on existential feedback and robust control systems, we take vulnerabilities—even theoretical ones—seriously. If you identify a structural flaw, prompt injection vector, or conceptual vulnerability in the Wh- Protocol or associated implementations, **please do not disclose it publicly by creating an issue.**

Instead, please practice responsible disclosure:

1. **Contact us privately:** You can report the vulnerability directly to the author, Eric Lin, via secure private messaging channels (if previously established) or use GitHub's Private Vulnerability Reporting feature for this repository.
2. **Provide details:** Please include a detailed description of the vulnerability, the potential impact on the "Identity State" or system stability, and any proof-of-concept (such as theoretical prompt injections or mathematical contradictions).
3. **Review:** We will review your report, assess its impact on the Survival Topology framework, and work with you to address it securely.

We appreciate your efforts in ensuring the theoretical robustness of the Survival Topology architecture.
