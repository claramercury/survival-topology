# Security Policy

## Supported Versions

The Survival Topology project is currently a theoretical markdown documentation project. As such, versioning primarily applies to the documentation itself.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |

## Reporting a Vulnerability

We take the security and integrity of the conceptual control theory framework ("Wh- Protocol") seriously.

If you discover a vulnerability or security-related issue in the Survival Topology documentation, please do not open a public issue. Instead, practice responsible private disclosure.

Please report all security vulnerabilities directly to the author, Eric Lin, via email at:
**[eric26752196@gmail.com](mailto:eric26752196@gmail.com)**

We will make every effort to respond to your report promptly. Please include a detailed description of the issue, the potential impact, and any steps required to reproduce or understand the vulnerability in the context of the theoretical framework.
