# Security Policy

## Supported Versions

Currently, only the latest version of the documentation is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for us. If you discover a security vulnerability within this project, please responsibly disclose it.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to the project maintainer. Please include the following information in your report:

- The type of vulnerability.
- A description of the vulnerability.
- Any potential impact.
- Steps to reproduce the vulnerability (if applicable).

We will try to acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a fix is implemented, we will notify you before the public release.
