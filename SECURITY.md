# Security Policy

## Supported Versions

The "Survival Topology" project is primarily a theoretical framework and documentation repository. We ensure that the conceptual ideas presented are rigorously evaluated for potential misuse.
The current supported version for security updates is the latest version available on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our conceptual control theory framework ("Wh- Protocol") seriously.
If you believe you have found a critical security vulnerability or an architectural flaw that could lead to negative implications, please follow our **private responsible disclosure practice**.

1. **Do NOT** open a public issue or pull request for security vulnerabilities.
2. Contact the project author, Eric Lin, directly via email at: **<eric26752196@gmail.com>**
3. Please include the following details in your email:
   - A description of the vulnerability or architectural flaw.
   - Potential impact if the flaw is exploited or misused.
   - Any steps required to reproduce or conceptually model the issue.

We will review the submission as quickly as possible and work with you to resolve the issue responsibly. We appreciate your efforts to keep this project secure!
