# Security Policy for Survival Topology

## Supported Versions

Currently, the master version of the documentation and conceptual architectural principles (on the `main` branch) is being actively maintained. We welcome security evaluations and conceptual analyses of the "Wh- Protocol" framework.

## Reporting a Vulnerability

Security is a primary concern for the Survival Topology project.

If you believe you have discovered a vulnerability or theoretical risk in the Survival Topology framework, please **do not open a public issue.** We request that you responsibly disclose the issue privately.

Please report any security concerns directly to the project author via email:
**Eric Lin** - `eric26752196@gmail.com`

Please provide details about the potential vulnerability, including steps to reproduce it or conceptual proofs of the flaw. The author will try to acknowledge your report as quickly as possible and coordinate a fix or architectural revision.

Thank you for helping to improve the security of the Survival Topology framework.
