# Security Policy

## Supported Versions

The "Survival Topology" project is currently a theoretical documentation repository. We accept security reports that impact the infrastructure of this repository or outline theoretical security flaws within the conceptual framework, particularly those involving implementation consequences.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is highly prioritized within this framework. If you have discovered a vulnerability, we appreciate your help in disclosing it to us in a responsible manner.

To report a security vulnerability:

1.  **Do NOT open a public issue.**
2.  Please contact the maintainer directly via private channels (e.g. security email if provided, or through private messaging if available).
3.  Include a clear description of the vulnerability, its potential impact, and instructions on how to reproduce the issue.

You will receive an acknowledgment of your report within 48 hours. We will keep you updated as we investigate the vulnerability and work on a resolution. Once the vulnerability has been resolved and deployed, we will disclose the finding, granting credit to the reporter.
