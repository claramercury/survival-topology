# Security Policy

## Supported Versions

Currently, this repository is focused on documentation, and there are no active software versions maintained with security updates. However, we are committed to resolving any security issues found within our infrastructure or materials.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to the maintainers. Do not disclose vulnerabilities in public issues.

We will review the vulnerability and provide an update on its resolution as soon as possible.
