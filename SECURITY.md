## Reporting a Vulnerability

We take the security of this project seriously.

If you discover a security vulnerability in this project, please report it privately. **Do not create public issues for security vulnerabilities.**

Please email security reports to [security@example.com] (Note: Replace this placeholder with an actual contact email).

We will try to acknowledge receipt of the vulnerability report within 48 hours and work with you to address it promptly.
