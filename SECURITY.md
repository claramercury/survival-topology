# Security Policy

## Supported Versions

The "Survival Topology" project is primarily a theoretical framework and documentation repository. Security considerations mainly pertain to the conceptual architectural principles and integrity of the documentation.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a critical component of the Wh- Protocol, as a system's ability to resist entropy is paramount.

If you discover a vulnerability or security-related issue in the "Survival Topology" documentation, proposed architecture, or associated conceptual models, we kindly ask that you practice responsible, private disclosure.

**Please DO NOT open a public issue.** Public disclosure of unpatched conceptual flaws may undermine the security posture of systems implementing these principles.

Instead, please report any security vulnerabilities directly to the author:
**Eric Lin: [eric26752196@gmail.com](mailto:eric26752196@gmail.com)**

### What to include in your report

* A description of the vulnerability or conceptual flaw.
* The specific section or theoretical component affected.
* Potential impact or exploitation scenarios.
* Suggested mitigation or correction.

We appreciate your effort in helping to secure the Survival Topology framework!
