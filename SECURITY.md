# Security Policy

## Supported Versions

Currently, the master implementation and documentation of the **Survival Topology** framework and **Wh- Protocol** in the `main` branch are supported.

## Reporting a Vulnerability

As the **Survival Topology** project involves critical conceptual architectural security principles, we take vulnerabilities very seriously.

If you discover a vulnerability or security risk (especially related to the Wh- Protocol, the 7 Seals definitions, or theoretical model implementations), please DO NOT open a public issue. We mandate private responsible disclosure practices to protect the framework.

Please report the vulnerability by emailing the project author directly:
**Contact:** eric26752196@gmail.com

We will review the report and work with you to implement a fix before public disclosure.
