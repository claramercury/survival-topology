# Security Policy for Survival Topology

Thank you for your interest in the security of the Survival Topology project. This document outlines our security policies and how to report vulnerabilities.

## Supported Versions

Currently, the Survival Topology framework and its foundational concepts are actively maintained. While this branch (main) primarily hosts theoretical documentation and conceptual frameworks (the "Wh- Protocol"), any discovered vulnerabilities in its theoretical design or associated tools should be reported.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

We prioritize the security of the Survival Topology project. If you discover a security vulnerability or identify a critical conceptual flaw, we ask that you practice **private responsible disclosure**.

### How to Report

Please do **NOT** open public issues or pull requests to report security vulnerabilities. Instead, send an email directly to the project author, **Eric Lin**, at:

**[eric26752196@gmail.com](mailto:eric26752196@gmail.com)**

### What to Include

When reporting a vulnerability, please include:

* A clear description of the vulnerability or flaw.
* The potential impact or exploit scenario.
* Steps to reproduce the issue (if applicable).
* Any suggested remediation or theoretical corrections.

### Our Response

We will endeavor to acknowledge receipt of your vulnerability report within 48 hours and provide updates on our progress as we evaluate and address the issue. We deeply appreciate your efforts to help improve the security and integrity of the Survival Topology framework.
