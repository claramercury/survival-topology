# Security Policy

## Supported Versions

The conceptual framework detailed in "Survival Topology: A Control Theory Framework for General Intelligence" relies on ongoing theoretical developments rather than traditional software releases.
However, we still prioritize the security of the ideas, equations, and any associated theoretical code examples.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As the Survival Topology is an open-loop architectural proposal mapping control theory to AGI, security issues may pertain to algorithmic flaws, existential feedback vulnerabilities in the proposed architecture, or errors in the provided theoretical Python simulation code that might be maliciously exploited if implemented into an actual AGI agent.

Please do not open public issues for any critical theoretical or code vulnerabilities that could be misused. Instead, practice private responsible disclosure by contacting the author directly.
