# Security Policy for Survival Topology

Thank you for your interest in the security of the Survival Topology project. We take security vulnerabilities seriously and appreciate the community's efforts in identifying them.

## Supported Versions

Currently, the primary documentation and architectural concepts (the "Wh- Protocol") on the `main` branch are in draft status and maintained for conceptual integrity. Any security-related architectural suggestions or theoretical vulnerabilities in the framework should be directed as described below.

For related project components (such as the Android application on separate branches), please refer to their respective release cycles if applicable.

## Reporting a Vulnerability

**DO NOT create a public issue for a security vulnerability.**

If you discover any security issue, theoretical flaw in the protocol, or any other vulnerability, please practice responsible private disclosure.

Please report the vulnerability directly via email to the project author, Eric Lin, at:
**eric26752196@gmail.com**

In your report, please include:

- A descriptive title for the vulnerability.
- A detailed description of the vulnerability, including its potential impact.
- Steps to reproduce the issue or a theoretical breakdown of the flaw.
- Any suggested mitigations or fixes.

You will receive an acknowledgment of your report, and we will work with you to address the issue securely before any public disclosure.
