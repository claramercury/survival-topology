# Security Policy

## Supported Versions

Currently, the master version of the documentation and framework concepts is supported. There is no active software component in the `main` branch, but theoretical or architectural security findings are welcome.

## Reporting a Vulnerability

We take the security of the Survival Topology framework and its implementation very seriously.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them privately via email to the project author, Eric Lin, at:
`eric26752196@gmail.com`

You should receive a response within 48 hours. If the issue is confirmed, we will work with you to outline a timeline for a fix and provide updates on our progress.

### What to include

When reporting a vulnerability, please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Any relevant context or potential solutions if you have them.

Thank you for helping keep the Survival Topology project secure!
