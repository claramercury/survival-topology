# Security Policy

## Supported Versions

At present, only the current main branch version of the "Survival Topology" conceptual documentation is actively maintained for security purposes.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Thank you for contributing to the security of the Survival Topology project.

Due to the conceptual nature of the Survival Topology project ("The Wh- Protocol" documentation), security issues are primarily conceptual, architectural, or related to the presentation of the documentation itself.

**To report a vulnerability or raise a security concern:**

Please practice **Private Responsible Disclosure**. Do NOT open a public issue for any security-related concern.

Instead, please send an email directly to the project author, Eric Lin, at:
**<eric26752196@gmail.com>**

Please include the following details in your email:

- A clear description of the vulnerability, risk, or concern.
- Steps to reproduce or understand the issue.
- Potential impact and any suggestions for remediation or conceptual adjustments.

You should expect an initial response acknowledging the receipt of your report within a reasonable timeframe. The issue will be evaluated and addressed privately before any public announcement or changes are made to the repository.
