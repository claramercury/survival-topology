# Security Policy

## Supported Versions

Currently, as this is a theoretical and conceptual framework, no versions are actively supported with security updates. However, the author welcomes discussions on potential theoretical vulnerabilities in the architecture.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report any security concerns, conceptual flaws, or vulnerabilities by opening an Issue on the repository or contacting the author directly if contact information is available. Do not create public issues for critical vulnerabilities.

If you find a theoretical exploit in the Survival Topology framework, please provide:
- A description of the vulnerability.
- Steps to reproduce the conceptual flaw.
- Potential impact on the proposed AGI architecture.
