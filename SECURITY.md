# Security Policy for Survival Topology

Thank you for your interest in the security of the Survival Topology project. As an open-source framework conceptualizing closed-loop control systems for Artificial General Intelligence (the "Wh- Protocol"), we prioritize the security and integrity of our theoretical architecture and documentation.

## Supported Versions

Currently, the theoretical framework is in its initial draft stage on the main branch. Any security issues pertaining to the conceptual integrity or foundational documentation are of critical importance.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We request that all security vulnerabilities or conceptual flaws be reported privately to ensure responsible disclosure.

Please do **NOT** open public issues or pull requests for security vulnerabilities.

Instead, please send an email to the project author, Eric Lin, at:
**eric26752196@gmail.com**

Please include the following information in your report:

* A detailed description of the vulnerability or conceptual flaw.
* The potential impact on the Survival Topology framework.
* Step-by-step instructions to reproduce the issue.
* Any proposed mitigations or fixes.

We will endeavor to respond to your report promptly, confirm the vulnerability, and work with you on a resolution before public disclosure.

Thank you for helping secure the future of closed-loop intelligence.
