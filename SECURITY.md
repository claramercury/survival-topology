# Security Policy

## Supported Versions

We currently support the following versions of the Survival Topology documentation:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover any security vulnerabilities or issues with this project, please do not disclose them publicly.
Instead, please open a private advisory on GitHub under the repository's Security tab to responsibly disclose the issue.

We take security seriously and will work to address any responsibly disclosed vulnerabilities as quickly as possible.
