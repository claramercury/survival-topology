# Security Policy for Survival Topology

## Supported Versions

The Survival Topology project is currently a theoretical framework and documentation repository. Security support is provided for the current draft of the framework.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |

## Reporting a Vulnerability

As this repository contains foundational documentation for the "Wh- Protocol" control theory framework and AGI architecture, the security of its concepts and any associated implementations is of the utmost importance.

If you discover a vulnerability, conceptual flaw, or security risk in the theoretical models or documentation presented, we strongly request that you practice private responsible disclosure.

**Please do not open a public issue for security-related concerns.**

Instead, please report any security issues or vulnerabilities directly to the author, Eric Lin, via email at:
eric26752196@gmail.com

### What to include in your report

* A detailed description of the vulnerability or security flaw.
* The specific section or concept in the documentation where the issue was found.
* Potential impact or risk associated with the vulnerability.
* Steps to reproduce or understand the flaw, if applicable.

We take all security reports seriously and will work to address them promptly while maintaining confidentiality. You can expect an initial response within 48 hours of your report.

Thank you for helping to secure the Survival Topology framework.
