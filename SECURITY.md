# Security Policy

## Supported Versions

Currently, the master branch containing the Survival Topology framework documentation is the primary focus. While this is purely a conceptual/architectural framework and lacks active source code elements on the main branch, we hold it to high philosophical security and safety standards.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We prioritize the safety and security of the conceptual frameworks we define, as their ultimate application is intended for General Intelligence models.

If you discover a vulnerability or a critical flaw in the Wh- Protocol, the control system logic, or have any other security-related concerns regarding the framework outlined in this repository:

**Please DO NOT open a public issue.**

Instead, practice responsible private disclosure by directly contacting the project author, **Eric Lin**, via email at:

**eric26752196@gmail.com**

Please include the following details in your report:

- A description of the vulnerability or architectural flaw.
- The theoretical impact on the "Identity State" or "Existential Feedback" systems.
- Any steps or reasoning to reproduce the conceptual failure.

We will acknowledge receipt of your vulnerability report within 72 hours and provide updates on the status of our internal review and the resolution timeline.
