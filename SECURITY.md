# Security Policy

## Supported Versions

Currently, the "Survival Topology" project is in draft version (v1.0). Only the `main` branch documentation and the current version of the project are supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of "Survival Topology" seriously. If you discover a vulnerability or a security-related issue within the project documentation or theoretical framework, we ask that you practice **private responsible disclosure**.

### How to Report

Please do **NOT** open a public issue on GitHub for security vulnerabilities. Instead, send an email to the project author:

- **Eric Lin:** [eric26752196@gmail.com](mailto:eric26752196@gmail.com)

### What to Include

When reporting a vulnerability, please provide the following information:

1. A clear description of the vulnerability and its potential impact.
2. Steps to reproduce the issue (if applicable).
3. Any relevant context from the "Wh- Protocol" or control theory framework that may be impacted.
4. Suggested remediation or mitigation strategies.

### Response Time

We will strive to acknowledge your report within 48 hours and will keep you informed of our progress towards resolving the issue. We appreciate your efforts to help keep "Survival Topology" secure.
