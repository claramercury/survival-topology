# Security Policy for Survival Topology

As the "Survival Topology" architecture aims to provide a robust control theory framework for General Intelligence, it's critical that the principles of security and resilience are maintained throughout this project.

## Supported Versions

Currently, the `main` branch (Version 1.0 Draft) of the Survival Topology framework is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |

## Reporting a Vulnerability

Security is a primary concern for the Survival Topology and the Wh- Protocol.

If you discover any security-related vulnerabilities, flaws in the conceptual framework that could lead to exploitation, or implementations that violate the core principles of identity and survival:

1. **DO NOT** open a public issue. Exposing vulnerabilities publicly before they are addressed can threaten the integrity of the system.
2. **DO** report the issue directly via email to the project author:
   **Eric Lin** - [eric26752196@gmail.com](mailto:eric26752196@gmail.com)

### What to Include in Your Report

To help us effectively evaluate and resolve the issue, please include:

* A detailed description of the vulnerability.
* The specific part of the Survival Topology equation or Wh- Protocol module affected.
* Potential impact and exploit scenarios.
* Any proof-of-concept or steps to reproduce the vulnerability (if applicable).

We take all reports seriously and will acknowledge receipt of your vulnerability report promptly. We will work to investigate and resolve the issue following responsible disclosure practices.
