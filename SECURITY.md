# Security Policy for Survival Topology

## Supported Versions

The following versions of the Survival Topology project are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of the Survival Topology framework seriously. If you discover a security vulnerability in this project, we ask that you practice responsible disclosure.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them directly to the project author, Eric Lin, by emailing:
**eric26752196@gmail.com**

Please provide as much information as possible, including:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We will endeavor to respond to your report as quickly as possible and work with you to resolve the issue responsibly.
